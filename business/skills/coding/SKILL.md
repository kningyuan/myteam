# 编码交付 — SKILL

本 Skill 指导 Agent 在收到「编码」类任务时如何编排工作。

## 流程

1. **需求分析** — 复述理解的任务需求，确认输入输出
2. **设计方案** — 概要设计：模块划分、接口定义、数据结构
3. **代码实现** — 按设计方案编码，遵守项目代码规范
4. **测试结果** — 运行单元测试或集成测试，记录覆盖率

## 红线

- 禁止引入未经 task_type 或 plan.md 允许的外部依赖
- 代码须在项目仓库内可复现构建
- 交付目录包含 source + 测试结果
- 必须验证代码可通过编译/语法检查
