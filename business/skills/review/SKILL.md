# 评审交付 — SKILL

本 Skill 指导 Agent 执行评审类任务。

## 流程

1. **评审范围** — 与被评审方确认评审范围和材料
2. **逐项审查** — 对每个评审维度做逐项检查
3. **问题列表** — 记录发现的缺陷、不一致、冗余
4. **改进建议** — 给具体可执行改进方案

## 审查维度

- 功能完整性：是否覆盖全部需求点
- 代码质量：可读性、安全性、性能
- 架构一致性：是否符合系统设计约定
- 文档准确性：注释与文档是否与实际代码一致

## 红线

- 每个问题必须有具体引用（行号/URL/文件名）
- 禁止模糊评语（「建议优化」→ 必须说怎么优化）
- 改进建议须按优先级排序
