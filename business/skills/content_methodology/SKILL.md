# 内容创作方法论

## 任务描述
进行内容创作、排版、配图等工作，产出高质量的内容交付物。

## 标准流程
1. **需求分析** — 明确受众、平台、风格要求
2. **内容策划** — 大纲设计、素材收集
3. **内容创作** — 撰写正文、配图说明
4. **排版优化** — 格式规范、可读性优化
5. **审核发布** — 事实核查、风格检查

## 必选章节
- 内容定位与受众分析
- 内容大纲与素材来源
- 正文（含配图说明）
- SEO 优化建议
- 发布平台适配说明

## 工具推荐
- Markdown 编辑器 — 内容创作
- Canva / Figma — 配图制作
- Grammarly — 语法检查

## Gate 规则
- 内容须有明确的目标受众
- 配图须有来源标注
- 事实性内容须有来源支撑
