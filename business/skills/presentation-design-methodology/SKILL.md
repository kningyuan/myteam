# 演示文稿设计方法论

## 任务描述
设计并产出专业级演示文稿（HTML Deck / PPTX），要求故事线清晰、视觉专业、数据可视化有效，避免"标题+项目符号"的流水账式幻灯片。

## 故事结构

### 1. 经典叙事弧线
```
Hook（吸引注意）→ Problem（定义问题）→ Solution（提出方案）
→ Evidence（证据支撑）→ Impact（预期影响）→ Call to Action（行动号召）
```

### 2. 常见结构模板

| 场景 | 结构 | 页数 |
|------|------|------|
| 产品发布 | 痛点 → 方案 → Demo → 优势 → 路线图 | 12-15页 |
| 技术分享 | 背景 → 挑战 → 架构 → 实现 → 效果 → 总结 | 15-20页 |
| 方案汇报 | 现状 → 问题 → 方案 → 实施计划 → 预期效果 → 风险 | 10-15页 |
| 竞品分析 | 评估维度 → 逐项对比 → 差异分析 → 策略建议 | 10-12页 |
| 年度总结 | 目标回顾 → 关键成果 → 数据分析 → 经验沉淀 → 来年规划 | 15-20页 |

### 3. 每页设计原则
- **一页一观点** — 每页只传达一个核心信息，标题就是结论
- **3秒法则** — 观众 3 秒内能理解这页在说什么
- **6x6规则** — 每页不超过 6 行，每行不超过 6 个词（中文 12 字）
- **对比优先** — 用大小/颜色/位置建立视觉焦点

## 视觉设计

### 色彩
- **主色板**：1 主色 + 1 辅色 + 1 强调色 + 中性色（黑/白/灰）
- **暗色背景**：#0F0F0F 背景 + #E5E5E5 文字 + 品牌色强调
- **亮色背景**：#FAFAFA 背景 + #1A1A1A 文字 + 品牌色强调
- **数据可视化**：使用色盲友好色板（Okabe-Ito / Tableau 10）

### 排版
- **字体**：中文用 Noto Sans CJK SC / 思源黑体，英文用 Inter / IBM Plex Sans
- **字号阶梯**：标题 48-64px / 副标题 24-32px / 正文 18-20px / 注释 14px
- **行距**：标题 1.2 / 正文 1.5
- **对齐**：统一左对齐或居中对齐，不混用

### 布局
- **网格系统**：12 列网格，内容区占 8-10 列，留白 2-4 列
- **安全边距**：四周 ≥48px（PPT 16:9 下）
- **视觉层次**：Z 型 / F 型 / 对称型 / 全屏图 + 文字叠加

## 数据可视化

### 图表选择

| 数据关系 | 推荐图表 | 不推荐 |
|----------|----------|--------|
| 趋势变化 | 折线图 / 面积图 | 饼图 |
| 对比分析 | 柱状图 / 条形图 | 雷达图（>5维） |
| 占比分布 | 环形图 / 百分比堆叠 | 3D饼图 |
| 相关性 | 散点图 / 气泡图 | 表格 |
| 流程转化 | 漏斗图 / 桑基图 | 饼图 |
| 地理分布 | 地图 / 热力图 | 表格 |

### 数据可视化原则
1. **一图一结论** — 标题就是结论（如"Q3 营收同比增长 42%"）
2. **去除 chartjunk** — 删除网格线/3D效果/渐变填充/多余图例
3. **标注关键数据** — 在图表上直接标注重点数值，不依赖坐标轴
4. **统一色板** — 全文使用同一套数据可视化色板
5. **数据来源** — 每张图表底部标注数据来源

## 输出规范

### HTML Deck（推荐）
- 自包含 HTML 文件，浏览器直接打开
- CSS 动画过渡（fade/slide），不用复杂 JS 动画
- 支持全屏演示（`requestFullscreen`）
- 响应式适配（16:9 / 4:3）
- 中文字体显式声明：`Noto Sans CJK SC` / `WenQuanYi Micro Hei`

### PPTX
- 16:9 宽屏
- 母版统一（标题/正文/章节页/结尾页）
- 嵌入字体或使用系统通用字体
- 图片分辨率 ≥150 DPI

## 反模式清单

| 反模式 | 问题 | 替代 |
|--------|------|------|
| 标题+项目符号 | 信息密度低，观众读不进去 | 全屏图+关键结论 |
| 全文字幻灯片 | 视觉疲劳，无记忆点 | 图表/图标+精简文字 |
| 3D饼图 | 视觉误导，不专业 | 扁平环形图 |
| 动画过多 | 分散注意力 | 仅在关键转折处使用 |
| 小字号 | 后排看不清 | 正文 ≥18px |
| 花哨背景 | 干扰内容 | 纯色/微妙渐变 |

## 必选章节
- 故事结构设计（含每页核心观点列表）
- 视觉规范（色板/字体/字号/布局网格）
- 数据可视化设计（含图表选择理由）
- 反模式走查清单
- 输出格式说明（HTML/PPTX）

## Gate 规则
- 每页须有明确的结论性标题，不能只写主题词
- 须含至少 2 张数据可视化图表
- 中文字体须显式声明
- 反模式清单须逐条走查
- HTML 输出须自包含（无外部 CDN 依赖）
