# 爬虫方法论

## 任务描述
针对目标网站设计并实现数据采集方案，包含采集策略、数据提取规则、反爬应对措施、数据清洗流程与合规检查，产出可运行代码与数据集。

## 标准流程

### 1. 目标分析
- **robots.txt 检查** — 确认目标站点允许采集的路径与频率限制
- **页面结构分析** — 识别列表页/详情页/分页/无限滚动等结构
- **数据量级评估** — 预估总数据量、单页数据量、采集耗时
- **更新频率** — 判断数据更新周期，决定全量/增量策略

### 2. 采集策略
- **广度优先（BFS）** — 适用于目录式站点，先采列表页再采详情页
- **深度优先（DFS）** — 适用于链式页面，沿链接逐层深入
- **并发控制** — 单域名并发 ≤3，总并发 ≤10
- **请求间隔** — 随机延迟 2-5 秒，避免固定间隔被识别
- **重试机制** — 指数退避重试（1s → 2s → 4s → 8s），最多 3 次
- **断点续采** — 记录已采集 URL，支持中断后恢复

### 3. 数据提取
- **CSS 选择器** — 优先使用，可读性最好（`soup.select('.item-title')`）
- **XPath** — 适用于复杂层级关系（`//div[@class="content"]/p[1]`）
- **正则表达式** — 仅用于非结构化文本中的模式匹配
- **JSON-LD / 结构化数据** — 优先解析 `<script type="application/ld+json">`
- **API 逆向** — 检查 Network 面板是否有内嵌 API，直接调用更稳定

### 4. 反爬应对

| 反爬手段 | 应对策略 |
|----------|----------|
| User-Agent 检测 | 轮换 UA 池（≥10个真实浏览器 UA） |
| IP 频率限制 | 代理池轮换（每 IP ≤50 请求/小时） |
| 验证码 | 降速 + 人工介入标记，不暴力破解 |
| JS 动态渲染 | Playwright / Puppeteer 无头浏览器 |
| 登录态 | Cookie 池管理，定期刷新 |
| 加密参数 | 分析加密逻辑，用 requests/httpx 复现 |

### 5. 数据清洗
- **去重** — URL 去重 + 内容哈希去重（SHA256 前 16 位）
- **格式标准化** — 日期转 ISO 8601、金额转分、文本 trim + HTML 实体解码
- **缺失值处理** — 标记 NULL，不填充默认值
- **数据校验** — 字段类型、值域、关联一致性检查

### 6. 合规检查
- 遵守 robots.txt
- 不采集个人隐私数据（身份证/手机号/地址）
- 采集频率不影响目标站点正常服务
- 数据用途符合目标站点 Terms of Service

## 技术选型

| 场景 | 推荐工具 | 说明 |
|------|----------|------|
| 静态页面 | requests + BeautifulSoup | 轻量快速 |
| JS 渲染页面 | Playwright | 支持 SPA、可截图 |
| 分布式采集 | Scrapy + Redis | 队列调度 + 断点续采 |
| API 逆向 | httpx + httpie | HTTP/2 支持 |
| 数据存储 | SQLite / CSV / JSON | 按数据量选择 |

## 必选章节
- 目标站点分析（含 robots.txt 检查结果）
- 采集策略与并发参数
- 数据提取规则（选择器/XPath）
- 反爬应对方案
- 数据清洗与存储格式
- 合规检查结论

## Gate 规则
- 须输出 robots.txt 检查结果（允许/禁止路径）
- 采集代码须包含重试与断点续采逻辑
- 须声明采集频率与并发数
- 数据清洗须包含去重与格式标准化步骤
- 须有合规检查结论（Pass/Fail）
