# 第四章：数据分析与洞察提炼

## 三大分析工具

### 1. 对比矩阵

- 行：竞品（3-4 个）
- 列：分析维度（4-6 个）
- 格子：具体数据 + 来源标注
- 必须有"分析洞察"列

### 2. SWOT 分析

- **优势（Strengths）**：我方相对对手的长处
- **劣势（Weaknesses）**：我方相对对手的短板
- **机会（Opportunities）**：对手没覆盖的市场空间
- **威胁（Threats）**：对手即将发力的方向

### 3. 洞察提炼

- 每个发现须有数据支撑
- 洞察 ≠ 罗列（要有差异化判断）
- 战略含义：这个发现意味着什么

## 洞察 vs 罗列

- ❌ 罗列：Cursor 支持 Agent，Windsurf 也支持 Agent
- ✅ 洞察：Cursor 的 Agent 强调自主性（数周运行），Windsurf 强调多 Agent 协作管理
