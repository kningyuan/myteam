# Data Analysis Methodology

## 任务描述
对给定数据进行系统性分析，产出包含数据来源、分析方法、关键发现和行动建议的完整报告。

## 标准流程
1. **数据采集** — 明确数据源、采集方式、数据量级
2. **数据清洗** — 缺失值处理、异常值检测、数据转换
3. **探索性分析** — 描述性统计、分布分析、相关性分析
4. **深度分析** — 按分析目标选择合适的方法（回归/聚类/时间序列等）
5. **可视化** — 选择合适的图表类型，确保可读性和准确性
6. **结论提炼** — 基于数据得出结论，给出可执行建议

## 必选章节
- 数据来源与质量
- 分析过程与方法
- 关键发现（至少 3 条）
- 结论与行动建议
- 局限性说明

## 工具推荐
- pandas / numpy — 数据处理
- matplotlib / seaborn — 可视化
- scipy / statsmodels — 统计分析
- plotly — 交互式可视化

## Gate 规则
- 须含可复现的分析脚本路径
- 数据清洗规则须明确说明
- 每个结论须有数据支撑
- 可视化图表须有标题和标注
