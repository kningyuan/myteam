# Prompt优化方法论

## 任务描述
优化 Agent 的 worker prompt，提升任务执行质量和交付物水平。

## 优化原则
1. **明确意图** — 任务目标清晰，避免歧义
2. **结构化约束** — 用明确的格式要求替代模糊描述
3. **示例引导** — 提供正反面示例
4. **渐进复杂度** — 从简单到复杂逐步展开
5. **验收标准** — 明确定义什么算"完成"

## 优化流程
1. 分析原始 prompt 的问题（模糊/缺失/矛盾）
2. 识别关键约束和验收标准
3. 重构 prompt 结构（意图 → 约束 → 格式 → 示例）
4. 验证优化效果（通过 Gate 检查或人工评审）

## 适用场景
- 新 task_type 的 prompt 设计
- 低质量交付物的 prompt 调整
- 跨平台发布的 prompt 定制
