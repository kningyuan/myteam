# 运营方法论

## 任务描述
针对产品/平台制定运营策略，覆盖用户增长、内容规划、活动设计、数据监控与社群管理，产出可执行的运营方案与效果评估体系。

## 核心框架

### 1. AARRR 增长模型

| 阶段 | 核心指标 | 关键策略 |
|------|----------|----------|
| **获取（Acquisition）** | 新用户数、获客成本（CAC）、渠道转化率 | 渠道测试 → 优化投放 → 规模化优质渠道 |
| **激活（Activation）** | 注册转化率、首次核心行为率、激活时长 | 缩短 Onboarding 路径 → A/B 测试引导流 |
| **留存（Retention）** | 次日/7日/30日留存率、DAU/MAU 比值 | 核心功能体验优化 → Push/邮件召回 → 习惯养成机制 |
| **收入（Revenue）** | ARPU、付费转化率、LTV/CAC 比 | 定价策略 → 付费功能设计 → 升级路径 |
| **传播（Referral）** | 邀请转化率、K因子（>1为病毒传播） | 分享激励机制 → 社交货币设计 |

### 2. 内容运营
- **内容日历** — 按周/月规划主题，提前 2 周备稿
- **选题策略** — 热点追踪（百度指数/微信指数）+ 常青内容（SEO）+ 用户痛点（评论区/客服）
- **内容矩阵** — 引流内容（60%）+ 专业内容（30%）+ 品牌内容（10%）
- **发布频率** — 公众号 3-5篇/周，小红书 1-2篇/天，知乎 2-3篇/周
- **效果度量** — 阅读量/互动率/收藏率/转化率，不只看阅读量

### 3. 活动运营
- **活动类型** — 拉新活动、促活活动、转化活动、品牌活动
- **设计流程**：
  1. 明确目标（拉新 X 人 / 转化 X% / GMV X 万）
  2. 确定预算与资源
  3. 设计玩法机制（简单可理解，参与门槛 ≤3 步）
  4. 制定规则与风控（防刷、防薅羊毛）
  5. 预热 → 上线 → 监控 → 收尾 → 复盘
- **复盘模板**：目标 vs 实际 → 差异分析 → 经验沉淀 → 下次改进

### 4. 数据驱动
- **指标体系** — 北极星指标（1个）→ 一级指标（3-5个）→ 二级指标（10-15个）
- **看板设计** — 实时看板（DAU/异常告警）+ 日报（核心指标趋势）+ 周报（对比分析）
- **归因分析** — 渠道归因（首触/末触/线性）、活动归因（增量分析）
- **实验文化** — A/B 测试先行，数据驱动决策，不靠直觉

### 5. 社群运营
- **社群分层** — 核心用户群（500人内）/ 活跃用户群（2000人内）/ 泛用户群
- **社群节奏** — 每日话题 → 每周活动 → 每月福利
- **KOL 培养** — 识别活跃用户 → 赋能（工具/权限/曝光）→ 反哺社区
- **氛围维护** — 及时回复（30分钟内）、定期清理广告、营造互助文化

## 必选章节
- 运营目标与北极星指标
- AARRR 各阶段策略与指标
- 内容运营计划（含内容日历）
- 活动运营方案（含预算与预期效果）
- 数据监控看板设计
- 社群运营策略

## 工具推荐
- 数据分析 — Google Analytics / 神策数据 / Mixpanel
- 内容管理 — 新榜 / 西瓜数据 / 蝉妈妈
- 社群管理 — 企业微信 / Discord / 飞书
- A/B 测试 — Optimizely / GrowthBook
- 数据可视化 — Metabase / Superset

## Gate 规则
- 北极星指标须为单一可量化数值，不可多个并列
- AARRR 各阶段须有具体策略，不能只列框架
- 活动方案须包含预算与预期 ROI
- 内容计划须包含发布频率与效果度量方式
- 数据看板须区分实时/日报/周报三个层级
