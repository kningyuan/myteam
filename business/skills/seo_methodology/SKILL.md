# SEO方法论

## 任务描述
进行 SEO 相关的关键词研究、内容优化、外链建设等工作，提升网站搜索排名。

## 标准流程
1. **关键词研究** — 发现高价值关键词，分析竞争强度
2. **内容优化** — 基于关键词优化标题、正文、Meta 标签
3. **技术分析** — 检查页面速度、移动端适配、结构化数据
4. **外链建设** — 寻找高质量外链机会
5. **效果追踪** — 监控排名变化、流量增长

## 必选章节
- 目标关键词列表
- 竞争对手分析
- 页面优化建议
- 技术 SEO 检查
- 外链建设计划
- 效果追踪指标

## 工具推荐
- Google Search Console — 搜索表现分析
- Ahrefs / SEMrush — 关键词研究
- PageSpeed Insights — 页面性能

## Gate 规则
- 关键词须有搜索量和竞争度数据
- 优化建议须有具体操作步骤
- 外链建设须有目标网站质量评估
