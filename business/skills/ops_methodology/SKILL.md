# 运维方法论

## 任务描述
进行运维相关的部署、监控、告警等工作，确保系统稳定性和可维护性。

## 标准流程
1. **部署规划** — 明确部署范围、回滚预案、健康检查
2. **部署执行** — 按步骤执行，记录操作日志
3. **健康检查** — 验证服务状态、性能指标、错误率
4. **监控配置** — 设置告警规则、监控面板
5. **文档更新** — 更新部署文档、运维手册

## 必选章节
- 部署范围与环境
- 部署步骤与回滚预案
- 健康检查结果
- 监控告警配置
- 后续优化建议

## 工具推荐
- Docker / Kubernetes — 容器化部署
- Prometheus / Grafana — 监控面板
- ELK / Loki — 日志分析

## Gate 规则
- 须有明确的回滚步骤
- 健康检查须有具体指标
- 监控配置须覆盖关键路径
