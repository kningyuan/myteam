# 迪诺链 · 架构分层说明（Agent 必读）

## 产品架构 — 四层模型

### L1 基础设施层
| 方块 | 说明 |
|------|------|
| 区块链核心 | 联盟链/许可链节点、共识、账本、交易池 |
| 双足预言机 | 分布式+中心化双向预言机，多源校验 |
| 跨链协议 | 跨链消息、资产映射、中继与验证 |
| 内容存储系统 | 链上哈希+链下对象存储、密态分包 |

### L2 组件层（每组件独立方块）
数字身份组件、属性组件、存证组件、溯源组件、消息组件、资产组件、合约研发组件、合约部署组件、合约测试组件、权限组件、加密组件、索引组件、网关组件、隐私计算组件、共识组件、节点管理组件、密钥管理组件、审计组件、通知组件、数据同步组件、费率组件、事件订阅组件

### L3 通用系统层（组件组合）
数字身份关系系统、访问控制系统、开发者服务系统、区块链 BaaS 系统、资产管理系统、运营监控系统、风控阻断系统、开放服务系统、联盟治理系统、跨链互联系统、合约生命周期管理系统、密钥托管系统

### L4 业务产品平台层
存证平台、溯源平台、协作平台、运营监管平台、数据共享平台、RWA 资产平台、合约集市平台、政务协同平台

---

## 系统架构 — 部署视图（与 L1–L4 可映射）

| 区域 | 方块 |
|------|------|
| 接入层 | 应用 SDK、REST API、Web UI、密钥解锁 API |
| 区块链网关 | 应用对接、业务适配、接口限流、多链路由、链上链下融合 |
| 开放服务集群 | 数字身份服务、资产索引服务、权限索引服务、ISV 插件服务 |
| 协作链服务 | 跨链身份互认、资产索引聚合、开放能力注册 |
| 工作链/行业链 | 医保链、财政链、税务链、司法链等业务链实例 |
| 链核心 | 共识模块、合约虚拟机、密态存储、交易执行引擎 |
| 链下适配 | 双足预言机、跨链中继、内容存储、业务系统连接器 |
| 运维安全 | 监控告警、日志审计、密钥 HSM、国密算法模块 |

**一致性检查**：产品架构「组件层」能力须在系统架构「开放服务/网关/链核心」中找到落地；业务平台须在接入层+开放服务上有明确入口。
