## 1. 共同目标（三角色一致）

myteam 的**最终形态**是：

> **工业级、可审计、可重复的多 Agent 编排框架** — 声明式 workflow + 任务级 Gate + 预算治理 + 可观测；Chat 与编排两条正交流；CLI 可插拔；人确认后合入变更（L3 不自推远端）。

**不是**：一个只能跑 self-upgrade 的专用脚本集合。`reg_l3_*` 属于**场景发版门禁**，不等于框架能力。
