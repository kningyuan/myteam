### T3.4 消息重复问题

| 项 | 详情 |
|----|------|
| **操作** | 查看群聊消息流 |
| **预期** | 消息按时间排序，无重复 |
| **实际** | 同一条任务完成通知重复了 50+ 次 |
| **结果** | ⚠️ 有 Bug |

**Bug 详情**：
- **严重度**：中
- **现象**：群 `p_demo` 中同一条 "📋 ✅ 任务完成" 通知重复渲染了 50+ 次
- **消息内容**：完全相同的任务完成通知
- **可能原因**：消息去重逻辑失效，或 SSE 事件重复消费
- **影响**：影响阅读体验，可能导致消息混乱
