## 知识沉淀闭环流程

### 预期闭环流程

```
任务执行
   ↓
质量评估 (QU) → 评分规则 (RU)
   ↓
经验抽提
   ├─ 交付报告 (RE)
   ├─ 基线数据 (BA)
   ├─ 案例记录 (CA)
   └─ 最优技能 (OP)
   ↓
知识入库 (L3 知识库)
   ↓
检索复用
   ├─ 新项目启动时检索相关知识
   ├─ Agent 执行时参考历史经验
   └─ Skill 自动推荐最优配置
   ↓
质量验证
   ├─ 知识准确性验证
   ├─ 复用效果评估
   └─ 过时知识淘汰
   ↓
持续优化 ←──────────┘
```
