## 5. 上线建议

### 结论：**通过（有条件）**

相比首轮的"有条件通过"，当前状态大幅改善。12 个缺陷中 **7 个已修复**，剩余 5 个中仅 1 个 S1（测试覆盖）对线上影响有限。

### 通过条件

**建议上线前修复**：

1. **[S1-003] R2/R3 核心功能单元测试** — 优先为 workspace_event、ProjectionRunner、EventPipeline、job CRUD、agent_runtime 编写至少 P0 级测试

2. **[S2-02] Demo 目录 README.md** — 5 分钟即可补充

**建议上线后迭代**：

3. **[S2-04] mark-final 和版本对比** — 非 MVP 阻塞，归入后续迭代
4. **[S3-01] 前端模块化** — R3-7 已在计划中，继续拆分 app.js/style.css
5. **[S4-01] Demo 环境** — 正确配置 CLI 后验证 E2E 流程
6. **[S4-02] 庆祝态** — 低优先级体验增强

### 风险剩余

| 风险 | 等级 | 说明 |
|------|:----:|------|
| 无 R2/R3 回归测试 | 中 | 后续修改可能破坏现有功能 |
| Demo E2E 无法跑通 | 中 | 需要 CLI 正确配置 |
| `_KERNEL_RUNS` 未完全迁移 | 低 | `POST /api/projects/run` 仍用内存 dict |
