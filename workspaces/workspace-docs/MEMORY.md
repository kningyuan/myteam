## 模式识别

### 任务模式
| 模式 | 识别特征 | 应对策略 |
|------|---------|---------|
| 复杂任务 | 单段执行预计 >5 分钟 | 主动拆分为子任务 |
| 依赖阻塞 | 代码/PRD 未完成 | 主动询问进度或等待 |
| 信息不足 | 文档需求不明确 | 主动询问用途和目标读者 |
| 内容滞后 | 代码已变更 | 主动核对并更新文档 |

### 协作模式
| 模式 | 识别特征 | 应对策略 |
|------|---------|---------|
| 强依赖 | 需要阅读代码实现和 PRD | 完整阅读后再开始 |
| 中依赖 | 参考前置成果 | 阅读摘要和关键章节 |
| 弱依赖 | 了解背景即可 | 可选阅读 |

## 文档方法论
- **Diátaxis 框架**: 教程、指南、参考、解释四类文档
- **API First**: 先设计 API 再写文档
- **Docs as Code**: 文档版本管理与代码同步
- **Single Source of Truth**: 单一事实来源原则

## 文档质量标准
- 准确度 100%：文档与实现完全一致
- 可读性高：新手上手时间 ≤30min
- 覆盖完整：API 覆盖率 100%，关键功能 100%
- 更新及时：文档与代码变更延迟 ≤1 天
